# 학습 시스템

---

## 학습 신호 5층

시스템이 스스로 개선되기 위해 수집하는 신호.

| 층 | 종류 | 수집 시점 | 특징 |
|----|------|----------|------|
| A | 일회성 선택지 | 페르소나 보강 시 | 초기 설정 때 한 번 수집 |
| B | 반복 선택지 (이유 포함) | 알림 응답·자소서 검토 시 | 매 사이클마다 누적 |
| C | 자유 입력 | 본인 명시 피드백 | 가끔, 고품질 신호 |
| D | 자동 감지 | 알림 무시 시간·수정 diff | 백그라운드 수동 없이 수집 |
| E | 외부 결과 | 합격·탈락 | 수집 방식 = 개발 직전 결정 (M1) |

## RAG 메타 학습 (#36)

### 무엇을 RAG로 학습하나

도메인 지식 — 개인 데이터가 아닌 모든 외부 정보:
- 회사 규모별 평점컷
- 산업 트렌드·요구 역량
- 면접 기출 문제
- 자소서 노하우·구조 패턴

### 시간 정책

| 시기 | 적용 데이터 |
|------|-----------|
| 초창기 | 과거 + 최신 데이터 검증 후 학습 |
| 안정기 | 최신 데이터만 |

### 작동 흐름

```
RAG 검색 (외부 도메인 지식)
    ↓
Claude 종합 → 잠정 기준 제시
    ↓
초기: 본인과 논의 후 적용
후기: 자동 적용 → 반영
```

## 자체 AI 학습 진화 (옵션 C — 전문 에이전트 진화형)

| 시점 | 외부 LLM 의존 | 자체 AI | 방식 |
|------|-------------|--------|------|
| v1 초기 | 100% | 0% | 자체는 관찰·데이터 수집만 |
| v1 후기 | 70~95% | 5~30% | 영역별 부분 자립 시작 |
| v2 | 50% | 50% | 오픈소스 파인튜닝 (Llama·Mistral) |
| v3+ | 10% | 90% | 비지도·자기지도 학습 |

### v1부터 준비할 것

자체 AI 학습을 위해 지금부터 저장해둬야 하는 것:
- 라벨 여부
- 타임스탬프
- 컨텍스트
- 수정 이력

## 자동화 전환 기준 (#30)

```
검증AI N회 연속 OK
    ↓
자동화 단계 상승 (N값 = 미결 M4)

패스 비율 임계점 도달
    ↓
필터 자동화 전환

본인 최소 승인
    ↓
단계 확정
```

## 갱신 시계열 (#37)

모든 데이터 갱신은 시계열로 관리:
- 저장 항목: **변경 전 / 변경 후 / 사유 / 트리거 / 타임스탬프**
- 인덱싱: 년 → 월 → 일 계층
- 기능: 자연어 검색 + 롤백 가능

## 외부 LLM 역할 분담

| LLM | 역할 |
|-----|------|
| **Gemini** | 웹 탐색·링크 추적 → JSON 변환 → Claude 전달 |
| **Claude** | 자소서·이력서 생성·검증·분석 등 핵심 생성 |

> 두 LLM 모두 부트스트랩 도구. 자체 AI 성숙도에 따라 점진 대체.
