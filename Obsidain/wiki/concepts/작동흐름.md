# 작동 흐름 — 전체 사이클

---

## 1단계: 최초 셋업 (처음 1회 + 필요 시 갱신)

```
① 자소서·이력서 파일 첨부
        ↓
② Claude가 페르소나 11섹션 자동 추출
        ↓
③ 목표 직무 채팅으로 입력
        ↓
④ 보강 질문 5~7개 (미결 M5)
        ↓
⑤ 응답 완료 → 페르소나 확정 · DB 저장
```

---

## 2단계: 반복 업무 사이클

```
① 공고 탐색·수집
   공식 API (사람인·워크넷·잡알리오)
   + Gemini 웹탐색 (API 없는 곳)
   → JSON 표준 형식으로 통일
        ↓
② 1차 필터링·매칭
   페르소나 제약조건 대조
   (급여·위치·업종·근무조건 등)
        ↓
③ ✋ HITL1 — 텔레그램 알림
   [지원] / [패스] / [보류]
        ↓ 지원              ↓ 패스
        ↓            → 패스 처리 흐름 (아래 참조)
④ 자소서 자동 생성
   3-소스 합성
   (본인 과거 글 + 공개 합격 자소서 구조 + 본인 피드백)
   문체 마커 6종 적용 / 안티패턴 4종 회피
        ↓
⑤ 검증AI (1차 룰 + 2차 LLM)
   실패 시 재시도 최대 3회
   3회 초과 → 폐기 + 본인 알림
        ↓ 통과
⑥ ✋ HITL2 — 본인 자소서 검토
   [승인] / [수정] / [폐기]
        ↓ 승인
⑦ 지원 (v1 = 지원 링크 전달)
        ↓
⑧ 결과 추적 (합격·탈락·미응답)
        ↓ 합격 시
⑨ 면접 준비 + 회고
        ↓
⑩ 학습 신호 누적 → 다음 사이클 개선
        ↓
   ① 로 반복
```

---

## 패스 처리 흐름 (③에서 [패스] 선택 시)

```
공고 [패스] 선택
        ↓
회사 평판 분석
  RAG로 규모별 평점컷 자동 검색
  규모별 차등 (대기업 / 중견 / 중소 / 스타트업)
  Claude 반어법·문맥 이해 → 판단
  본인 행동 패턴으로 보정
  초기: 본인 검토 / 학습 후: 자동 적용
        ↓
   [부적합 판정]
        ↓
┌────────────────────────────────────────────┐
│ 동일조건 반복 (3일~3개월)                   │→ 영구 배제
│ 같은 회사 + 다른 부서 공고                  │→ 알림 유지
│ 본인이 직접 해제 명령                       │→ 룰 무효화
│ 취직 후 이직 모드 전환                      │→ 룰 전체 초기화
└────────────────────────────────────────────┘
```

## HITL 2지점 — 점진 자동화 계획

| 시기 | HITL1 (지원 결정) | HITL2 (자소서 승인) | 자동화 전환 트리거 |
|------|-----------------|-------------------|--------------------|
| 초기 | 모든 공고 본인이 직접 판단 | 모든 자소서 본인이 직접 검토 | — |
| 중기 | 1차 필터 통과분 중 일부만 | 검증OK 통과분만 본인 검토 | 패스 비율 임계점 도달 |
| 후기 | 자동 (비상시 개입) | 자동 (사후 확인) | 검증AI N회 연속 OK (N=미결 M4) |

> 각 단계 전환은 본인 최소 승인으로 확정한다.

## 알림 시스템

- **채널**: 텔레그램 (단방향/양방향 = 미결 M9)

| 단계 | 내용 | 발송 시점 |
|------|------|----------|
| 1차 | 조건·자격·마감·경쟁률 | 공고 발견 즉시 |
| 2차 | 회사 상세·평판 | 검토 요청 시 |
| 3차 | 권장 판단 | 성숙기 자동 |
