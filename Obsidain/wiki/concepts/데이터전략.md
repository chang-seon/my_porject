# 데이터 전략

---

## 자소서 학습 — 3-소스 합성

| 소스 | 역할 | 가중치 기준 |
|------|------|-----------|
| 본인 과거 글 | 문체·문장 호흡 학습 | AI 작성 이전 글 위주 |
| 공개 합격 자소서 | 구조·논리의 메타패턴 | 표절 금지, **구조만** 참고 |
| 본인 피드백 | 승인·수정·거부 신호 | 운영하면서 누적 |

### 시기별 문체 가중치

| 문서 시기 | 가중치 | 이유 |
|----------|--------|------|
| α·β (2023) | **높음** | AI 작성 이전, 본인 문체 순도 높음 |
| γ (2025) | 중간 | AI 혼합 사용 시기 |
| δ (2025~26) | **낮음** | GPT 영향 강함 → 콘텐츠만 활용 |

## 3-풀 분리

```
콘텐츠 풀
  경험·에피소드 저장
  직무별 라벨링 (미결 M7)
  
구조 풀
  논리 흐름·단락 패턴
  공개 합격 자소서 구조 메타
  
문체 풀
  어휘·리듬·문장 호흡
  본인 문체 마커 6종 기반
```

## 본인 문체 마커 6종 (자소서 생성 시 반드시 반영)

| # | 마커 | 예시 |
|---|------|------|
| 1 | 따옴표 강조 | '도전', '중재' 같은 키워드를 따옴표로 강조 |
| 2 | 첫째·둘째·셋째 나열 | 경험이나 이유를 순서 있게 나열 |
| 3 | "비록 ~없지만 ~하였습니다" 도입부 | 한계 인정 후 극복 서술 |
| 4 | 구어체 잔재 | "일사천리로", "터득하여" 등 자연스러운 구어 |
| 5 | "성황리에/무사히" 결과 어휘 | 결과 서술 시 특정 어휘 사용 |
| 6 | 마무리 = 직무명 + 따옴표 다짐 | "'AI 에이전트 개발자'로서 ~" |

## GPT 안티 패턴 4종 (자소서 생성 시 반드시 회피)

| # | 패턴 | 설명 |
|---|------|------|
| 1 | 클리셰 동사 남용 | "체계적으로/효율적으로/기여하고자" 반복 사용 |
| 2 | 균일 만연체 | 문장 길이가 60~80자로 단조롭게 반복 |
| 3 | 명사화 과잉 | "○○을 통해 ○○할 수 있는 ○○" 구조 남발 |
| 4 | 도식적 마무리 | 문단마다 회사명·직무명으로 끝맺음 |

## 자소서 생성 정책 — "있는 사실 안에서 거짓말"

```
✅ 허용
  콘텐츠 풀에 있는 사실의 윤색·강조·연결·미화·과장

❌ 금지
  풀에 없는 사실 만들기
  (없는 경력·자격·기술·수치 창작)
```

- 윤색·과장 부분은 본인 검토 시 표시 → 승인 후 학습 누적
- 커리어 단계별 톤:
  - 신입 → 도전·학습·성장
  - 주니어 → 실무·성과
  - 경력 → 수치·리더십

## 데이터 격리·공유 (#38)

```
개인 데이터 (user_id 격리)
  ├─ 페르소나 (11섹션)
  ├─ 자소서·이력서
  ├─ 콘텐츠·구조·문체 풀
  ├─ 지원 기록·회고
  ├─ 학습 신호
  └─ 사용자 기준값

공유 지식 (전체 사용자 공유)
  ├─ RAG 메타 (회사 평점컷·산업 트렌드·면접 기출)
  ├─ 사회 통념
  └─ 산업 정보
```

## 페르소나 시트 11섹션

| 섹션 | 내용 |
|------|------|
| 신원 | 생년월일·주소 등 (본인 별도 입력) |
| 목표 직무 | AI 에이전트 개발자 |
| 콘텐츠 자산 | 킬러 에피소드 3종 + 맥락 필드 |
| 스킬·자격 | Python, SQL, NumPy, Pandas 등 |
| 문체 카드 | 문체 마커 6종 |
| 안티패턴 | 회피 패턴 4종 |
| 성격·강약점 | 자기인식 내용 |
| 가치관 | 업무 철학·우선순위 |
| 제약 | 급여·위치·근무조건 |
| 메타 (학습 기록) | 피드백·수정 이력 |
| 커리어 단계 | 신입 → 주니어 → 경력 |

### 킬러 에피소드 3종 ("맥락" 필드 필수 보존)

| 에피소드 | 핵심 메시지 |
|---------|-----------|
| 뉴질랜드 어학연수 (초4, 누나만 동행) | 도전·독립 |
| 굿네이버스 인형극 봉사 (투표 방식 제안해 갈등 해결) | 협업·중재 |
| 사회복지 실습 (어르신 가족 갈등 중재) | 경청·문제해결 |
